# shuf, uniq

## 1. shuf

입력된 데이터의 순서를 무작위로 섞어서 출력할 때 사용하는 명령어이다.

기본 형식:

```bash
shuf [OPTION]... [FILE]
```

또는:

```bash
shuf -e [OPTION]... [ARG]...
shuf -i LO-HI [OPTION]...
```

---

## 2. shuf 주요 옵션

### `-e`

```bash
shuf -e ARG...
```

- 입력한 argument를 각각 하나의 입력 라인처럼 취급

### `-i`, `--input-range=LO-HI`

```bash
shuf -i LO-HI
```

- 지정한 숫자 범위를 입력값으로 사용

### `-n COUNT`

```bash
shuf -n COUNT
```

- 출력할 개수를 지정

### `-o FILE`, `--output=FILE`

```bash
shuf -o FILE
```

- 결과를 지정한 파일로 출력

### `-r`, `--repeat`

```bash
shuf -r
```

- 결과를 반복해서 출력

---

## 3. uniq

중복된 라인을 처리할 때 사용하는 명령어이다.

```bash
uniq
```

---

## 4. uniq 주요 옵션

### `-c`, `--count`

```bash
uniq -c
```

- 각 라인의 중복 횟수를 함께 출력
- `-u`, `-d` 옵션과 함께 사용할 수 있음

### `-d`, `--repeated`

```bash
uniq -d
```

- 중복된 라인 중 한 번만 출력
- `-u` 옵션과 반대

### `-D`

```bash
uniq -D
```

- 중복되는 모든 라인을 출력

### `-u`

```bash
uniq -u
```

- 중복되지 않은 라인만 출력
- `-d` 옵션과 반대

### `-i`

```bash
uniq -i
```

- 강의 내용 기준: 중복 라인을 한 라인으로 간주하고 출력

### `-w N`

```bash
uniq -w N
```

- N번째 문자까지만 비교

### `-s N`

```bash
uniq -s N
```

- N번째 문자까지는 비교 대상에서 제외

### `-f N`

```bash
uniq -f N
```

- N번째 필드를 비교 대상에서 제외

---

## 5. 오늘 학습한 핵심 내용

```text
shuf
-e              : argument를 입력 라인으로 취급
-i LO-HI        : 지정한 숫자 범위를 입력으로 사용
-n COUNT        : 출력 개수 지정
-o FILE         : 파일로 출력
-r              : 반복 출력

uniq
-c, --count     : 중복 횟수 출력
-d, --repeated  : 중복 라인 중 한 번만 출력
-D              : 중복되는 모든 라인 출력
-u              : 중복되지 않은 라인만 출력
-i              : 강의 내용 기준 중복 라인 처리
-w N            : N번째 문자까지만 비교
-s N            : N번째 문자까지 비교 대상에서 제외
-f N            : N번째 필드를 비교 대상에서 제외
```
