# csplit, wc, echo, printf, yes, ls

## 1. csplit, wc

오늘은 `csplit`, `wc` 명령어를 학습했다.

### csplit 실습

```bash
csplit -f aa_
```

```bash
csplit k /REGEXP/ {4}
```

```bash
csplit k %REGEXP%
```

### 함께 학습한 명령어

```bash
wc
```
